# Contributing

Default guidance for `icyhoty2k` repositories. **A repository with its own
`CONTRIBUTING.md` overrides this one** — QuickImageViewer has its own, and its
licensing terms are the ones that apply there.

## The most useful thing you can do is report a bug well

More valuable than a patch, most of the time. What helps, in order:

1. **What you did, what happened, what you expected.** Three sentences beats three
   paragraphs.
2. **The version.** Every app shows it in its About box or screen.
3. **A file that reproduces it**, if a particular file triggers the problem. This is
   worth more than any description — image and document handling is where the awkward
   bugs live, and a real file is the only reliable way to reproduce one.
4. **Your OS**, and for Android apps the device and Android version.

## Before opening a pull request

**Open an issue first for anything beyond a small fix.** These are one-person projects
worked on in the evenings, and a large pull request that takes the design somewhere I
was not going is a sad thing for both of us — you spent the time, and I have to say no.
A short conversation first avoids that.

Typos, broken links, clear one-line bugs: just send them.

## Style

Match the file you are editing. Beyond that, two preferences that hold across every
repository here:

- **Imperative and explicit over clever.** A plain loop reads better than a chained
  functional one-liner. Control flow you can follow top to bottom beats an abstraction
  that hides the order of operations. If a declarative form is genuinely better, use it
  and say why in a comment.
- **Comments explain *why*, not *what*.** The code says what it does. A comment earns
  its place by recording the reason, the constraint, or the thing that was tried and
  did not work.

## Licensing

**Check the repository's `LICENSE` before writing code**, and read its own
`CONTRIBUTING.md` if it has one. Projects here are not all under the same terms, and
some require specific agreement from contributors. That is the one thing that cannot be
sorted out after the fact.
