# .github

Default community health files for every [`icyhoty2k`](https://icyhoty2k.github.io/)
repository.

GitHub applies these to any repository on the account that does not carry its own copy,
so a new project inherits them the day it is created. A repository's own file always
wins — QuickImageViewer has its own `CONTRIBUTING.md`, and that one applies there.

| File | Applies to |
|---|---|
| `CODE_OF_CONDUCT.md` | Every repository |
| `CONTRIBUTING.md` | Every repository without its own |
| `SECURITY.md` | Every repository |
| `FUNDING.yml` | Adds the Sponsor button |
| `profile/README.md` | Renders as the GitHub profile page at github.com/icyhoty2k |

Developer site: <https://icyhoty2k.github.io/>
