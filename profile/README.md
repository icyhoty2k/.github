### 🖥 [QuickImageViewer](https://github.com/icyhoty2k/QuickImageViewer)

A fast image viewer for Windows 10 and 11. Roughly sixty thousand lines of C++ written
directly against Win32 and Direct2D, with no UI framework underneath it — because the
only thing that matters is the moment between double-clicking a file and seeing the
picture. Forty-nine formats, 224 keyboard shortcuts, AGPL, and no paid tier.

[Download](https://github.com/icyhoty2k/QuickImageViewer/releases/latest/download/QuickImageViewer.exe) ·
[Website](https://icyhoty2k.github.io/QuickImageViewer/) ·
[Every shortcut](https://icyhoty2k.github.io/QuickImageViewer/shortcuts.html)

### 📱 qIV Remote

The Android companion. Turns a phone into a remote control, a second screen and a photo
frame for the desktop viewer, over your own network — next, previous, slideshow, zoom,
a live preview of what the PC is showing, and a fuzzy find that opens a picture when you
type part of its filename.

**It is in closed testing and needs testers.** Android 13 or newer, three steps, and the
same Google account for each:

1. [Join the group](https://groups.google.com/g/qiv-remote-testers)
2. Open [this link on the phone](https://play.google.com/apps/testing/net.icyhoty2k.qivremote) and tap **Become a tester**
3. [Install from Play](https://play.google.com/store/apps/details?id=net.icyhoty2k.qivremote) and keep it for fourteen days

Joining the group alone does not enrol you — step 2 is what does. You do not need a
Windows PC to try it; demo mode runs every screen without connecting to anything.

[What it does](https://icyhoty2k.github.io/QuickImageViewer/qiv-remote.html)

### How I work

Hand-written, no frameworks where a framework would cost speed. No accounts where an
account is not needed. No telemetry. Settings that survive a restart. A keyboard
shortcut for everything. And software that is *finished* rather than permanently in
progress.

Writing software is not my day job, which is exactly why it comes out this way — nobody
sets the deadlines, so the slow correct path is affordable.

More Android work next, and eventually games.
